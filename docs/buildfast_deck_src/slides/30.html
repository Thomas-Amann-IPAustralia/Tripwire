Stage 2change detection
Change Detection
Separates meaningful edits from cosmetic ones via three passes. FRL & RSS skip it — already structured.
1 Hash — SHA-256 match ⇒ skip
2 Diff — whitespace ⇒ cosmetic
3 Fingerprint — $, dates, terms,
   cross-refs, modal verbs
The fingerprint tags high vs standard — it never vetoes a real change.
