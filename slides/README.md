# Tripwire — Presentation Slides

`Tripwire_9-Stage_Architecture.pptx` — a 4-slide deck explaining the Tripwire
filter-funnel pipeline, styled after the project infographic (cream ground,
navy → blue → olive tier palette, funnel motif).

| Slide | Content |
|-------|---------|
| 1 | Overview of all 9 stages, grouped into the three tiers, with the filter-funnel graphic |
| 2 | Stages 1–3 — Detection & Pre-Processing (Metadata Probe, Change Detection, Diff Generation) |
| 3 | Stages 4–6 — Semantic Filtering (Relevance Scoring, Bi-Encoder Matching, Cross-Encoder Refinement) |
| 4 | Stages 7–9 — Assessment & Alerting (Trigger Aggregation, LLM Assessment, Notification) |

Stage descriptions are drawn from Section 3 of `260406_d_Tripwire_System_Plan.md`.

## Regenerating

The deck is generated by `build_slides.js` (uses `pptxgenjs`; icons rendered
from `react-icons` via `sharp`).

```bash
npm install pptxgenjs react react-dom react-icons sharp
node build_slides.js   # writes Tripwire_9-Stage_Architecture.pptx alongside the script
```
